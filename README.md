# Google Ads Scripts
Колекція скриптів для автоматизації та оптимізації рекламних кампаній.

- [Smart Monthly Auditor](https://github.com/deadweb/google-ads-scripts/tree/main/Smart%20Monthly%20Auditor) — Скрипт виводить кількість конверсій і витрати для вказаних акаунтів в таблицю Google Sheets. Працює як для окремих кампаній, так і для MCC.
- [Zombie Products Labeler](https://github.com/deadweb/google-ads-scripts/tree/main/Zombie%20Products%20Labeler) — Скрипт шукає "товари-зомбі" і записує їх ID в таблицю.
